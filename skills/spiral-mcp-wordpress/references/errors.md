# Errores frecuentes

| Síntoma o código | Causa | Qué hacer |
|---|---|---|
| `spiral_mcp_invalid_layout` | Tipo inexistente o anidado imposible (un headline dentro de una section, una row en la raíz, un item fuera de su padre) | Revisa la ruta con `get-layout-outline` y los tipos con `list-elements`. Los elementos van dentro de columnas. |
| `spiral_mcp_test_failed` | El layout cambió desde que lo leíste | Vuelve a leer el nodo (`get-layout-node`) y repite el patch con el valor actual. |
| `spiral_mcp_path_not_found` | Ruta mal escrita, o los índices cambiaron por un `add`, `remove` o `move` anterior en la misma petición | Las operaciones se aplican en orden: calcula cada ruta sobre el resultado de las anteriores. Para añadir al final usa `-`. |
| Prop desconocido en `warnings` | Nombre de prop incorrecto para ese tipo | `get-element-schema`. Los anchos de columna van en cada columna (son `child_props` de la fila). |
| Valor "no está entre sus opciones" en `warnings` | Valor no válido para un select | Usa uno de los `options` de `get-element-schema`. |
| El cambio de estilo no se ve | Falta recompilar el CSS | `get-style-status` → abre `recompile_url` en un navegador con sesión. |
| El cambio en un nodo con fuente dinámica no se ve | La fuente (`source`) sobrescribe el prop | Cambia el dato en su origen (título del post, menú…) o la propia `source`. |
| Una página no usa la plantilla | La página tiene layout propio, o hay otra plantilla antes que también encaja | Las plantillas solo se aplican sin layout propio y por orden de prioridad (`list-templates`). |
| `spiral_mcp_bad_url` al subir una imagen | URL no https, privada o local | Usa una URL https pública, o `data_base64` + `filename`. |
| `spiral_mcp_bad_type` al subir | Tipo no permitido (SVG, PHP…) o el contenido no coincide con la extensión | Convierte a jpg, png, webp o avif. |
| `spiral_mcp_bad_terms` | El tipo de contenido no admite esa taxonomía, o el término no existe | `list-post-types` (taxonomías por tipo) y `create-term`. |
| `spiral_mcp_not_trashed` | Se intentó borrar definitivamente algo que no está en la papelera | `trash-content` primero. |
| `spiral_mcp_section_locked` | Sección de configuración no editable (`yootheme_apikey`, `version`…) o `footer.content` | El footer se edita con `update-theme-layout` o `patch-layout` y `"area": "footer"`. |
| `spiral_mcp_unfiltered_html` (403) | El layout lleva un elemento `html` con `<script>`, `<iframe>` o atributos `on*`, y el usuario del agente no tiene `spiral_mcp_code` | No se ha guardado nada. Quita ese código (los textos normales van en un elemento `text`; para vídeos, el elemento `video`) o pide a la persona responsable el permiso `code`. En los elementos `text`, el HTML no permitido se elimina al guardar y se avisa en `warnings`. |
| `rest_ability_cannot_execute` / `ability_invalid_permissions` | Al usuario del agente le falta un permiso | Avisa a la persona responsable del sitio; no intentes rodearlo. |
| `ability_invalid_input` | Falta un parámetro obligatorio o tiene otro tipo | Revisa `references/abilities.md` (los obligatorios van en negrita). |
| `inspect-page` no carga la página | El servidor no se alcanza a sí mismo por su dominio | Pide que se configure el filtro `spiral_mcp_inspect_base_url`. Mientras tanto, revisa con la URL de `get-preview-url` en tu navegador. |
| `rest_ability_cannot_execute` en `update-cache-settings` | Falta el permiso de caché (`spiral_mcp_cache`), que el agente no tiene por defecto | Explica al usuario el cambio que harías; que lo haga en el panel de su plugin de caché o te conceda el permiso. |
| `spiral_mcp_online_disabled` | El administrador ha desactivado las descargas de la librería online (Ajustes > Spiral-MCP > Comportamiento) | Puedes enseñar el catálogo (`list-online-library`), pero no importar: díselo al usuario. |
| `spiral_mcp_plugins_disabled` / `spiral_mcp_plugins_capability` (403) | Falta un cerrojo de la gestión de plugins: el ajuste del administrador o la capacidad `spiral_mcp_plugins` | Explica al usuario cuál falta (lo dice el mensaje); no lo intentes por otra vía. |
| `spiral_mcp_plugin_fatal` / `spiral_mcp_plugin_broke_site` | El plugin da un error fatal o rompe la web al activarse | No ha quedado activo y el sitio funciona. Díselo al usuario y busca otra opción. |
| `spiral_mcp_plugin_protected` | Se intentó desactivar, actualizar o borrar Spiral-MCP-Control o MCP Adapter | No se puede desde aquí: sin ellos perderías el acceso. |
| `spiral_mcp_plugin_update_rolled_back` | La nueva versión daba error 500 en la portada o wp-admin | Ya se ha vuelto a la versión anterior. Díselo al usuario; no lo reintentes. |
| `spiral_mcp_plugin_no_update` / `spiral_mcp_plugin_source` | No hay actualización, o viene de fuera de wordpress.org (plugin de pago) | Si es de pago, que lo actualice el usuario desde wp-admin. |
| `spiral_mcp_plugin_active` (en `delete-plugin`) | Solo se borran plugins desactivados | Desactívalo antes con `deactivate-plugin` (con permiso del usuario). |
| `spiral_mcp_form_mail_confirm` | El cambio hace que los mensajes del formulario lleguen a otra dirección (destinatario, Cc/Bcc, adjuntos o correo 2) | Enséñale al usuario `data.changes` y repite con `"confirm": true` solo si lo aprueba. |
| `spiral_mcp_form_not_found` (404) | El formulario no existe (o el texto no coincide con ID, hash ni título) | Búscalo con `list-forms`. |
| Herramientas `*-form` ausentes | Contact Form 7 no está activo | Díselo al usuario; instalarlo es la receta «Instalar un plugin». |
| Herramientas de idiomas ausentes (`list-languages`…) | Polylang no está activo | Díselo al usuario; instalarlo es la receta «Instalar un plugin». |
| Herramientas de YOOtheme ausentes (`list-elements`, `patch-layout`, `get-theme-config`, plantillas, estilos…) | YOOtheme Pro no es el tema activo: no se registran | El diseño va por el builder del sitio: si hay `elementor/*`, con Elementor (ver «Sitios con Elementor» en `SKILL.md`). No escribas layouts de YOOtheme en `content`. |
| `spiral_mcp_elementor_content` (400) | La página está construida con Elementor y `content` no se mostraría | Edita el diseño con `get-elementor-outline` + `patch-elementor-data` (widgets clásicos) o `elementor/*` (V4); con `update-content` cambia solo título, estado, slug, padre, términos o imagen destacada. |
| `spiral_mcp_not_elementor` | El contenido no es de Elementor (`"builder"` distinto de `elementor`) | Para convertirlo, `update-elementor-data {"convert": true, "elements": [...]}`; si es una página de YOOtheme o de bloques, usa sus herramientas. |
| `spiral_mcp_invalid_elementor_data` (400) | Árbol mal formado (widget en la raíz, column fuera de una section, widget con hijos), tipo no registrado, widget de Elementor Pro en un sitio sin Pro, o elemento V4 nuevo | El mensaje dice la ruta y el tipo. Mira `list-elementor-widgets` y `get-elementor-widget-schema`; un V4 ya existente se conserva, pero no se crean: usa widgets clásicos. Un tipo no registrado hay que quitarlo (con permiso del usuario) o activar el plugin que lo aporta. |
| `spiral_mcp_element_not_found` | `element_id` o `parent_id` que no existe (o que cambió por una operación anterior de la misma llamada) | Vuelve a leer `get-elementor-outline`; `"document"` es la raíz. |
| `spiral_mcp_elementor_forbidden` (403) | Elementor no deja guardar con tu usuario: papelera, tipo de contenido sin Elementor, rol excluido en sus ajustes, página de entradas o de la tienda | El mensaje dice cuál; díselo al usuario (se cambia en Elementor > Ajustes). |
| `spiral_mcp_elementor_type_unsupported` | Plantilla de la biblioteca de un tipo que este sitio no tiene registrado (header o footer sin Elementor Pro) | No se puede guardar sin perder sus widgets: hace falta Elementor Pro activo. Tampoco se crean plantillas desde aquí. |
| `spiral_mcp_elementor_no_draft` | `publish-elementor-draft` sin borrador tuyo (los autosaves son por usuario) | Guarda antes con `"draft": true`; si ya está publicado, no hay nada que hacer. |
| `spiral_mcp_elementor_stale_draft` | Alguien guardó la página después de crear tu borrador | Léelo con `get-elementor-data {"draft": true}`, compáralo con la versión publicada y rehaz el cambio sobre la actual. |
| `spiral_mcp_unfiltered_html` (403) en Elementor | Widget `html` con script, iframe o atributos `on*` y tu usuario no tiene `unfiltered_html` | Elementor filtra con kses todo lo que guarda un usuario sin esa capacidad: usa text-editor, heading o image, o pide al usuario que lo pegue él. En los demás widgets el HTML peligroso se quita con aviso. |
| «ajuste desconocido» en `warnings` de Elementor | Nombre de ajuste incorrecto para ese widget (o un ajuste de estilo con el nombre de otro widget) | `get-elementor-widget-schema {"type": …, "tabs": ["all"]}`; las variantes responsive llevan sufijo `_tablet` / `_mobile`. |
| Herramientas `elementor/*` ausentes en un sitio de Elementor | El MCP de Elementor no está activado, o el administrador desactivó esas herramientas en Ajustes > Spiral-MCP | Solo hacen falta para elementos V4: los widgets clásicos van por `patch-elementor-data`. Si de verdad las necesitas, se activan en wp-admin > Elementor > Elementor MCP. |
| `elementor_v3_not_supported` en `elementor/manage-elements` | El elemento es un widget clásico, que el MCP de Elementor no edita | Usa `patch-elementor-data` de spiral-mcp con ese mismo `id`. |
| `elementor_v4_required` en `elementor/*` | El Editor Atómico no está activo | Para widgets clásicos no hace falta: usa las herramientas de Elementor de spiral-mcp. No pidas activar el Editor Atómico solo para retocar una página clásica. |
| 403 en `elementor/manage-global-variable`, `manage-default-styles`, `manage-component` o `manage-classes` | Elementor exige `manage_options` (o su capacidad de clases globales), que el rol del agente no tiene | Explica el cambio al usuario para que lo haga en el editor de Elementor, o que amplíe los permisos. |
| `spiral_mcp_pll_bad_language` | El idioma no existe en el sitio | Usa el `slug` o el `locale` de `list-languages`, o créalo con `create-language` si el usuario lo quiere. |
| `spiral_mcp_pll_translation_exists` | Ese contenido o término ya tiene traducción en ese idioma | Edita la que hay (el mensaje da su ID) o desenlázala antes con `update-translations` (`{"en": 0}`). |
| `spiral_mcp_pll_language_mismatch` | Al enlazar, el objeto está en otro idioma que el de su clave | Cambia antes su idioma (`update-translations` con `language`) o ponlo en la clave correcta. |
| `spiral_mcp_pll_not_translated` | Polylang no traduce ese tipo de contenido o taxonomía | Activa su traducción en `post_types` o `taxonomies` con `update-language-settings` (si el usuario lo quiere). |
| `spiral_mcp_pll_unknown_string` | El texto no está registrado para traducir (o no es exacto) | Copia el `original` de `list-string-translations`. Los textos que un tema registra solo en wp-admin no se pueden traducir desde aquí. |
| `spiral_mcp_confirm` en `update-language-settings` | El ajuste cambia las URLs de todo el sitio | Explícale al usuario qué URLs cambian y repite con `"confirm": true` solo si lo aprueba. |
| La traducción no tiene categorías o página madre | No estaban traducidas cuando se creó (`warnings`) | Tradúcelas con `create-translation` y asígnalas con `update-content` (`terms`, `parent`). |
| `spiral_mcp_snapshot_later` | Después de ese snapshot hubo otros cambios en el mismo objeto, y restaurarlo los desharía | Restaura solo la parte que toca (`"parts"`, en la configuración del tema) o revierte el valor con su herramienta. `"include_later": true` solo si el usuario quiere volver al estado completo. |
| Enlace roto con `target_status` en `inspect-page` | El destino existe pero no está publicado (borrador, programado…) | Publica el destino cuando el usuario lo apruebe, o cambia el enlace. La ruta está bien. |
| `warnings` de `get-menu` / `create-menu` sobre elementos en borrador | El menú enlaza a contenido sin publicar | Igual que arriba: el elemento se ve en el menú, pero da 404 hasta publicar. |
| Avisos de encabezados que no son de la página | Encabezados del tema (widgets, comentarios) | Los que tienen `"in_content": false` no cuentan para los avisos y no se arreglan en la página. |
